# Wigner and Q Functions of Quantum States

This repository contains Mathematica implementations for computing and visualizing Wigner and Husimi-Q quasiprobability distributions of various quantum states.

## Included states
- Vacuum state  
- Coherent state α  
- Fock states |1>, |4>  
- Superpositions: (|0> + |1>)/√2 , (|0> + i|1>)/√2  
- Mixed states  
- Schrödinger cat state |α> - |-α> (α=3)  
- Mixed coherent states  

## Tools
- Mathematica  
- Symbolic & numerical methods  

## Purpose
Part of my research work while preparing for PhD applications in theoretical and quantum statistical physics.
